# Db2 Vector Indexes
This folder holds SQL scripts for some simple tests with Db2 vector indexes. The files with prefix **r3** are for a table with threedimensional vectors and data based on random numbers. The files with prefix **r24** are used for vector data with 24 dimensions.

The files help demonstrate how to easily create / generate vector data, create a vector index, and see the index used or force its usage by applying optimization guidelines.
